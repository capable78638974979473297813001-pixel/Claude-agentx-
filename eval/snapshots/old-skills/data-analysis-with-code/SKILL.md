# Data analysis with code

- Never do non-trivial arithmetic in your head; run it.
- Inspect data first: shape, types, nulls, ranges, a few rows.
- Keep each step small and printed; build up the analysis.
- For engine checks: sweep an input grid, plot tax vs income and marginal
  rate vs income; look for jumps, negative slopes, and spikes.
- Report numbers with the script path so anyone can re-run them.
