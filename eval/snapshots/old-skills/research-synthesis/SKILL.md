# Research synthesis

1. Break the question into sub-questions that each have a factual answer.
2. For each, find primary sources first; secondary only for leads.
3. Extract claims as `claim — source — quote/location`.
4. Cross-check each important claim against a second independent source.
5. Synthesize: answer first, then evidence, then disagreements and gaps.
6. Mark confidence per claim (verified / single-source / inferred / unknown).
Never fill a gap with a plausible guess presented as fact.
