# Iterative canvas editing

1. Read the whole thing; state its purpose in one line.
2. Pass 1 **structure**: order, missing sections, things to cut.
3. Pass 2 **correctness**: facts, code, numbers.
4. Pass 3 **clarity**: shorter sentences, concrete words, consistent terms.
5. Pass 4 **polish**: formatting, examples, headings.
Edit in place with targeted changes. After each pass, list what changed in
one or two lines so the user can steer.
