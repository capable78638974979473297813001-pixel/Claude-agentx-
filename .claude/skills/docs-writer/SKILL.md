# Docs writer

- **README**: what it is (one line), quickstart that runs in < 1 minute, link to more.
- **How-to**: task-oriented ("Add a new tax year"), numbered steps, copy-pasteable commands.
- **Reference**: generated or tabular; every parameter, type, default, unit.
- **Design notes**: why, alternatives rejected, constraints.
Test every command you document. Cut words that don't change what the reader does.
