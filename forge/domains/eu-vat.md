- Standard rate plus reduced/super-reduced/zero rates set per member state within the framework of the VAT Directive.
- Place-of-supply rules decide which country's VAT applies; B2B cross-border services often use reverse charge.
- One-Stop Shop (OSS) schemes cover distance sales to consumers.
- Exempt (no input VAT recovery) vs zero-rated (recovery allowed) is a critical distinction.
- Invoice requirements and rounding rules are set nationally.

Never enter a rate, threshold, or date from memory as verified; cite a primary source or mark it UNVERIFIED.
